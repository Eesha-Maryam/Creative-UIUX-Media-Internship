# WEEK 12 — Case Study & Portfolio Presentation

## Project: LINKUP
**Tagline:** Where Ideas Connect People.

### 1. Project Overview
LINKUP is a community-driven mobile application designed to help people discover creative ideas, share thoughts, explore Idea Sparks, and connect with others for collaboration.

Week 12 focused on documenting the complete UX/UI design process and presenting the LINKUP project as a professional case study for portfolio development.

### 2. Objectives
- Present the complete UX/UI design journey.
- Organize research, planning, and design documentation.
- Showcase wireframes and high-fidelity UI screens.
- Document usability testing and participant feedback.
- Highlight design improvements made after testing.
- Prepare a professional case study presentation.

### 3. Work Completed

**UX Research & Planning**
- Problem Statement
- User Persona
- User Flow Diagram
- System Architecture Diagram
- Information Architecture Diagram

**UI/UX Design**
- Low-Fidelity Wireframes
- Branding & Design System
- Typography and Color Palette
- UI Components & Component Library
- High-Fidelity UI Designs
- Interactive Figma Prototype

**Usability Testing**
- Defined research goals and testing objectives.
- Prepared five usability testing tasks.
- Created a Google Forms feedback survey.
- Conducted testing with five participants.
- Analyzed quantitative ratings and qualitative feedback.

**Design Improvements**
Based on usability testing feedback, the following improvements were implemented:
- Added a Saved Ideas page.
- Added a My Contributions page.
- Introduced a Quick Guide page for new users.
- Improved the Profile page with Connections, Contributions, and Member Since information.
- Refined the interface based on identified usability issues.

**Case Study & Portfolio**
- Prepared a complete UX/UI case study presentation.
- Documented the design process from initial research to final prototype.
- Included before-and-after design comparisons.
- Showcased supporting media and brand applications.

### 4. Supporting Media & Brand Applications

### 6. Final Deliverables
- Complete LINKUP UX/UI Case Study Presentation.
- Updated High-Fidelity Mobile App Designs.
- Interactive Figma Prototype.
- Usability Testing Results and Analysis.
- Before-and-After Design Improvements.
- Supporting Brand and Media Designs.

### 7. Learning Outcomes
This project strengthened my understanding of the complete UX/UI design process, including user research, information architecture, wireframing, visual design, prototyping, and usability testing.

It also highlighted the importance of user feedback in identifying usability issues and making meaningful design improvements.
