# RAASTA Travel Poster

**Brand:** RAASTA - *“Every road has a story.”*
**Destination:** Lahore, Pakistan

## Project Overview

This project focused on creating a travel poster for Lahore that highlights its culture, heritage, and unique character through a modern and professional visual style.

The design process included typography exploration, color palette development, layout variations, visual research, and comparison of different poster directions before selecting the final design.

## Design Decisions

### Typography

Bold display fonts were paired with clean supporting fonts to create clear hierarchy while keeping the supporting information simple and readable.

* **Poster 1:** Anton + Montserrat
* **Poster 2:** Bebas Neue + Inter

### Color

Two color directions were explored. The final direction uses **Deep Teal, Terracotta, and Soft Sand** to create a modern and sophisticated look while maintaining a warm cultural connection.

### Layout

Two different approaches were explored:

* **Poster 1:** A large hero image creates an immersive and cinematic travel feel.
* **Poster 2:** Three Lahore landmarks create a more structured and modern composition.

### Hierarchy

The main brand and destination message receive the most attention, followed by the landmark imagery, supporting information, and **Explore Lahore** CTA.

### Grid & Spacing

A 6-column grid was used to keep elements aligned and maintain consistent spacing throughout the designs.

## Final Direction

The final direction was selected because it created the strongest balance between modern design, cultural identity, visual hierarchy, and readability. The teal background and three-image layout also gave the poster a clean and premium travel-poster feel.

## Project Outcome

The project helped me understand how typography, color, layout, hierarchy, and spacing work together to communicate a clear visual message. Exploring multiple directions before finalizing the design also helped me make design decisions based on purpose rather than appearance alone.
