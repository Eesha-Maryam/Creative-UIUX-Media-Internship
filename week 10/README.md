# LINKUP — Week 10: High-Fidelity UI & Prototyping

**Company:** Aurex  
**Project:** LINKUP — Where Ideas Find Their People  
**Week:** 10 — High-Fidelity UI & Prototyping

## Overview
LINKUP is a mobile application concept designed to connect people through shared ideas, knowledge exchange, and collaboration.

## Completed Work
- Created a complete design system with color palettes, typography, spacing, and reusable components.
- Designed 9 high-fidelity mobile screens, including Splash, Login, Sign Up, Discover, Create Idea Spark, Idea Details, My Board, Collaboration Space, and Profile.
- Built an interactive Figma prototype with screen navigation, sidebar interaction, and transitions.
- Applied consistent visual styling, component states, and micro-interactions.

## Tools Used
- Figma — UI design, components, and interactive prototyping.

## Deliverables
- High-fidelity UI screens
- Design system and component library
- Interactive prototype
